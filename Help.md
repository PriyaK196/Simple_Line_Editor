# Simple Line Editor - Help

## Available Commands

### 1. insert

Inserts a new line at the specified line number.

Example:

insert
Enter line number to insert: 1
Enter text: Hello World

---

### 2. delete

Deletes a line from the document.

Example:

delete
Enter line number to delete: 1

---

### 3. display

Displays all lines in the document with their line numbers.

Example:

display

Output:
1. Hello World
2. Welcome

---

### 4. save

Saves the current document into a text file.

Example:

save

---

### 5. load

Loads the previously saved document.

Example:

load

---

### 6. search

Searches for a word or phrase and displays the line number where it is found.

Example:

search
Enter text to search: Hello

Output:
Found in line 1: Hello World

---

### 7. help

Displays all available commands.

Example:

help

---

### 8. exit

Exits the Simple Line Editor.

Example:

exit
